# Dataset files go here

Download the two original CSV files from your group's Kaggle sources and put them in this folder:

1. Housing Prices Dataset: https://www.kaggle.com/datasets/yasserh/housing-prices-dataset
   - Expected filename in the default commands: `Housing.csv`
2. King County House Sales Prediction: https://www.kaggle.com/datasets/harlfoxem/housesalesprediction
   - Expected filename in the default commands: `kc_house_data.csv`

The actual CSVs are intentionally not bundled. Download them from Kaggle yourself, and do not rename or edit their columns unless you have confirmed the change with your group. If your downloaded filenames are different, update the command-line paths.
